# simplix-react <small>{{VERSION}}</small>

> Package-first React framework that derives the API client, hooks, forms and mocks from one contract

- One Zod contract for entities and their operations
- React Query hooks, form hooks and MSW mock handlers derived from it
- Domain packages generated from an OpenAPI spec by the CLI
- CRUD UI components, authentication, access control and i18n as packages
